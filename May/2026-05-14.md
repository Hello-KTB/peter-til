### 새로 배운 내용
#### 주제 1: Git & GitHub
- **Git** : 파일 변경사항을 추적하고 협업을 조율하는 분산 버전 관리 시스템(DVCS)
- **GitHub** : Git 저장소를 호스팅하는 웹 서비스 플랫폼
- **버전 관리 시스템 종류**
  - CVCS(중앙 집중식) : 서버에서만 관리 / 인터넷 필수
  - DVCS(분산식) : 로컬에도 전체 히스토리 보관 / 오프라인 작업 가능
- **Git 동작 흐름** : `Working Directory → Stage → History → Remote`
- **자주 쓰는 명령어**
  - `git init` : 저장소 초기화
  - `git add` : 스테이징
  - `git commit -m "메모"` : 변경 확정
  - `git push` : 원격 저장소 업로드
  - `git pull` : 원격 저장소 최신 내용 가져오기
  - `git clone` : 원격 저장소 복제
