## 새로 배운 내용

### 주제 1: 컴퓨터 언어

컴퓨터 언어 : 이진법을 이용하여 논리 연산, 저장을 수행하는 전자 기계와 소통하기 위한 수단

- 컴퓨터와 사람이 의사소통하기 위한 방법
- 명령을 전달하고 결과를 받기 위해 사용됨

#### 왜 이진법을 사용하는가?

- 컴퓨터는 전기적인 신호를 기반으로 동작함
- 열림(1), 닫힘(0)

### 기계어

#### 특징

- 컴퓨터가 직접 이해하는 언어
- 이진수로 이루어짐

#### 사용하는 이유

- CPU가 바로 해석하여 실행 가능하기 때문

#### 한계점

- 코드 가독성이 매우 낮음
- 코드 작성이 어려움
- 수정 및 유지보수가 힘듦

### 고급언어

#### 등장 배경

- 기계어의 불편한 점들을 해결하기 위해 읽고 쓰기 쉬운 고급 언어 등장

#### 특징

- 사람이 이해하기 쉬움
- 생산성이 높음
- 유지보수가 편리함

#### 대표적인 종류

- C
- C++
- Python
- Java
- JavaScript 등

### 주제 2: Java 기초

자바 : 다양한 플랫폼에서 실행될 수 있도록 설계된, 메모리 관리와 강력한 라이브러리 생태계를 갖춘 객체지향 프로그래밍 언어

#### 탄생 배경

##### 당시 상황

- 1980년대에는 주로 C와 C++을 사용함
- 특히 C언어는 운영체제 및 시스템 개발의 표준처럼 사용됨

##### 문제점

- 프로젝트 규모가 커질수록 유지보수가 어려움
- 제조사마다 사용하는 CPU 구조와 기계어 체계가 다름
- 하드웨어마다 별도로 프로그램을 준비해야 하는 번거로움 존재

##### 해결 시도

- 썬 마이크로시스템즈(Sun Microsystems)는 CPU와 운영체제에 상관없이 실행 가능한 언어를 만들고자 Java를 개발함

#### 특징

- 플랫폼 독립성
- 보안 안정성
- 메모리 관리
- 객체지향

### 주제 3: Java 메모리 관리

메모리 관리 : 프로그램에 필요한 저장 공간을 할당하고 해제하는 것

#### Java의 메모리 관리

##### 특징

- JVM 실행 시 운영체제로부터 메모리를 할당받음
- JVM이 메모리를 관리함

### Stack / Heap / GC

- 스택(Stack) : 실행 흐름을 담는 메모리 공간
- 힙(Heap) : 공용으로 사용하는 메모리 공간
- GC(Garbage Collector) : 힙 메모리 영역에서 더 이상 사용되지 않는 객체를 제거하는 기능

#### Stack

- 메서드 실행
- 지역 변수 저장
- 자동 생성 / 자동 제거

#### Heap

- 객체 저장
- 여러 곳에서 참조 가능
- GC가 관리
